⏺ Excellent research findings! Here's what I discovered:

  Claude Code Agent File Format

  Based on https://code.claude.com/docs/en/sub-agents and 
  https://claudelog.com/mechanics/custom-agents/, agents use this structure:

  ---
  name: agent-name
  description: When Claude should use this agent
  color: visual-identifier
  tools: Bash, Read, Write, Edit, Grep, Glob, etc.
  model: sonnet
  ---

  [Agent's system prompt and instructions go here]

  Multi-Agent Coordination (2025 Best Practices)

  From https://medium.com/data-science-collective/creating-multi-agent-workf
  lows-with-microsoft-agent-framework-8c68df1ec0ea and 
  https://asanshay.com/blog/agent-library:

  - Markdown-based communication: Agents write thoughts/responses to shared
  markdown files for asynchronous coordination
  - Sequential + concurrent orchestration: Agents can work in pipelines or
  parallel
  - Agent graphs: Defined roles with handoff channels between agents

  System Prompt Best Practices

  Key elements from https://theagentarchitect.substack.com/p/4-tips-writing-
  system-prompts-ai-agents-work and https://www.augmentcode.com/blog/how-to-
  build-your-agent-11-prompting-techniques-for-better-ai-agents:

  1. Clear role/personality definition
  2. Step-by-step execution mandate with explicit thinking phases
  3. Domain knowledge & constraints (style guides, best practices)
  4. Safety boundaries with refusal protocols
  5. Tool descriptions that are action-oriented
